개인정보처리방침

jionxai Studio · 시행일 2026-11-25

1. 받는 정보

운영자가 구글 허락 화면에서 허락한 유튜브 채널에 대해서만 아래 권한을 받습니다.

  • https://www.googleapis.com/auth/youtube: 영상 올리기, 공개 상태 · 제목 · 설명 · 썸네일 · 재생목록 바꾸기, 채널과 영상 정보 읽기
  • https://www.googleapis.com/auth/yt-analytics.readonly: 채널 · 영상 통계 읽기

2. 어디에 두나요

  • 연결 정보(토큰)는 운영자 PC 안, 운영자 사용자만 읽을 수 있는 폴더에만 둡니다.
  • 받은 통계는 운영자 PC 안의 회사 기록에만 둡니다.
  • 어떤 외부 서버로도 보내지 않습니다. 구글 API를 부를 때만 구글과 주고받습니다.

3. 누구와 나누나요

누구에게도 팔거나 넘기지 않습니다. 광고에 쓰지 않습니다. jionxai Studio가 구글 API로 받은 정보의 사용과 전달은 Google API Services User Data Policy를 따르며, 제한적 사용(Limited Use) 요건을 지킵니다.

4. 유튜브 API 서비스

이 프로그램은 YouTube API Services를 사용합니다. 사용하면 YouTube 서비스 약관에 동의하는 것이며, 구글의 정보 처리에는 Google 개인정보처리방침이 적용됩니다.

5. 연결 끊기와 지우기

  • 언제든 Google 계정의 서드파티 연결 페이지에서 jionxai Studio 접근을 끊을 수 있습니다. 끊으면 바로 더는 접근하지 않습니다.
  • 운영자 PC의 토큰 파일을 지우면 그 연결 정보도 사라집니다. 통계 기록은 운영자가 회사 기록에서 지울 수 있습니다.

Privacy Policy (English)

jionxai Studio is a personal program its operator runs on their own PC. It only accesses the YouTube channels the operator authorizes on Google's consent screen, with these scopes: https://www.googleapis.com/auth/youtube (upload videos; update visibility, title, description, thumbnail and playlists; read channel and video information) and https://www.googleapis.com/auth/yt-analytics.readonly (read channel and video analytics).

OAuth tokens are stored only on the operator's PC, in a folder readable only by the operator's user account. Analytics are stored only in the operator's local records. Nothing is sent to any server other than Google's APIs. No data is sold, shared or used for advertising. jionxai Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This program uses YouTube API Services. By using it you agree to the YouTube Terms of Service; Google's handling of data is covered by the Google Privacy Policy.

Access can be revoked at any time on the Google Account third-party connections page. Deleting the token file on the operator's PC also removes the stored authorization. Contact: github.com/Jiyong-Jeon. Effective 2026-11-25.
